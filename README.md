# 🔥 MSD KART - ECOMMERCE WEBSITE (https://msd-kart-frontend.onrender.com/)

A full-stack MERN application built using MongoDB, Express.js, React.js, and Node.js. This project demonstrates modern web development practices, authentication, dynamic UI, and CRUD functionality.

---

## 🚀 Features

- 🧺 Add to Cart / Order System
- 📦 Product Listing 
- 🌐 RESTful API with Express + MongoDB
- 💡 Responsive Design with React
- 🔐 Secure Routes & Token Validation

---

## 🛠️ Tech Stack

**Frontend**: React, HTML, CSS, JavaScript  
**Backend**: Node.js, Express.js  
**Database**: MongoDB (Mongoose)  
**Other**: Git, Render
